# Criando Um Organizador de Declaração de Imposto de Renda

Projeto desenvolvido no curso Santander Excel com Inteligência Artificial, da DIO.

## Objetivo

Criar uma ferramenta em Excel para centralizar informações utilizadas na preparação da declaração de Imposto de Renda, facilitando o preenchimento e a consulta dos dados.

## Organização da planilha

- **TÍTULO:** formulário com dados cadastrais do titular e opções de resposta SIM/NÃO.
- **INFORMES:** registro de até três bancos, valores e nomes dos arquivos de informes, com cálculo automático do total.
- **NOTAS:** registro das entradas por mês, categoria e valor.
- **BANCOS:** aba oculta com uma lista de instituições bancárias para apoio ao preenchimento.

## Recursos utilizados

- Menus com links para navegar entre as abas.
- Links de navegação “Anterior” e “Próximo”.
- Validação de dados com listas de opções.
- Fórmula para somar os valores bancários.
- Formatação de campos e organização visual dos formulários.

## Como utilizar

1. Baixe o arquivo `PROJETO IRPF - APP.xlsx` deste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Preencha os dados cadastrais na aba TÍTULO.
4. Registre os valores e as referências dos informes na aba INFORMES.
5. Preencha as entradas mensais na aba NOTAS.
6. Utilize os menus para consultar as informações.

Os nomes dos informes são referências aos documentos; os PDFs devem ser guardados separadamente.

## Aprendizados

O projeto permitiu praticar a criação de formulários no Excel, validação de dados, navegação por hiperlinks e consolidação de valores. A documentação no GitHub complementa a aplicação dos conceitos apresentados nas aulas.
